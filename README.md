# ITECH-STORE (mock)

Small React + Vite scaffold that reproduces the provided dark mobile UI.

Setup

```bash
npm install
npm run dev
```

Open the shown `localhost` URL in a mobile-sized viewport or use device emulation.

What I implemented

- Splash screen matching the attached mock
- Home screen: search, banner, categories, top picks grid
- Reusable `ProductCard` and basic dark-neon CSS

Next steps

- Replace placeholder product images with your assets (put in `src/assets/` and update `ProductCard`)
- Add product detail pages, routing, or animation as needed
